# 📁 Carpeta de Componentes

Esta carpeta está lista para que agregues tus componentes reutilizables de React.

## 💡 Sugerencias de organización

```
src/components/
├── ui/              # Componentes básicos de UI
│   ├── Button.tsx
│   ├── Input.tsx
│   └── Modal.tsx
├── forms/           # Componentes de formularios
│   ├── LoginForm.tsx
│   └── ContactForm.tsx
├── layout/          # Componentes de layout
│   ├── Header.tsx
│   ├── Footer.tsx
│   └── Sidebar.tsx
└── common/          # Componentes comunes
    ├── Loading.tsx
    └── ErrorBoundary.tsx
```

## 🎯 Mejores prácticas

- Usa nombres descriptivos en PascalCase
- Exporta componentes como default
- Incluye PropTypes o tipos TypeScript
- Mantén componentes pequeños y enfocados
- Reutiliza estilos con Tailwind CSS

¡Comienza a construir componentes increíbles! 🚀
